## What's inside

| Area | What you'll find |
|------|------------------|
| **Foundations** | Roadmaps for offensive, defensive, app-sec, cloud, DFIR and GRC; fundamentals in crypto, networking, OS and scripting; certification guides; courseware; glossary |
| **Hands-On Work** | Home-lab blueprints and vulnerable-app setups you can spin up locally |
| **Toolkit** | Tool breakdowns across recon, scanning, exploitation, post-exploitation, password cracking, network defense, cloud, containers, forensics, malware analysis and OSINT |
| **Cheatsheets** | Command, framework and payload cheatsheets for quick reference |
| **Research** | Curated blogs and books worth your time |
| **GRC** | Framework primers and ready-to-use templates |
| **DFIR & Malware Analysis** | IR playbooks, memory forensics, sandboxing guides and YARA rules |
| **Scripts** | Reusable scripts that back the library and its workflows |

## Getting started

This site is built with [MkDocs](https://www.mkdocs.org/) and the
[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme.

<div class="grid">

```bash
# Clone the repo
git clone https://github.com/cyber-compile/knowledge-base.git
cd knowledge-base

# Run locally
pip install -r requirements.txt
mkdocs serve
```

</div>

Once the server is up, open <http://127.0.0.1:8000> — the same site you see on
<https://cybercompile.com>.
